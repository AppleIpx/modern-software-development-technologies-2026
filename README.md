## Общий код

Повторяющийся код вынесен в пакет [`common`](common/) и используется только там, где это уместно:

| Модуль | Что делает | Используется в |
|---|---|---|
| `common/validation.py` | `is_strict_int`, `is_strict_bool`, `is_positive_int` (`bool` не считается числом) | `task_11` |
| `common/console.py` | `read_positive_int`, `read_non_negative_int` — ввод целого с повтором | `task_10`, `task_11` |
| `common/numbers.py` | `is_odd` | `task_9`, `task_10` |
| `common/jsonio.py` | `read_json`, `write_json` (UTF-8, кириллица читаема) | `task_11` |

Кроме того, `task_10` импортирует `table.py` из `task_9` вместо копии файла.

Намеренно **не** вынесено:

- **Задания 1–6.** Условие требует последовательный код без функций (функции вводятся в работе 7), поэтому небольшие повторы там — часть задания.
- **Задание 12.** По условию проект должен запускаться после распаковки в другую папку, поэтому он автономен и не зависит от `common` и других заданий.
- **Задания 7 и 8.** Повторов с остальными нет.

Из-за общего кода задания 9–11 нужно запускать из корня репозитория (как и описано в инструкциях).

## Как запустить

Нужен [uv](https://docs.astral.sh/uv/). Внешних зависимостей нет — используется только стандартная библиотека Python 3.13+; окружение управляется через uv.

```bash
uv sync                               # создать/обновить окружение (.venv)
uv run python -m task_1.variant       # запуск программы: пакет.модуль без .py
uv run python -m task_7.test_functions  # запуск проверок
uv run python -m task_12.main         # итоговый проект
```

Команды выполняются из корня репозитория. Точные команды для каждой программы — в README соответствующего задания. Задание 11 (`fetch_profile`) обращается к GitHub API и требует интернет; без сети используйте `read_sample`.
